# Dokumentasi Website Perpustakaan SMKN 2 Purwakarta

Website perpustakaan digital berbasis Laravel 10 untuk **SMKN 2 Purwakarta** — mengelola koleksi buku, anggota, peminjaman, dan administrasi perpustakaan dalam satu website yang sepenuhnya responsif (desktop & mobile).

- [03. Quick Start](01-getting-started/03-quick-start.md) — Jalankan website dan langkah mencoba fitur
